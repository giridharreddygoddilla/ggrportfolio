## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. View in browser at http://localhost:5173/ or http://127.0.0.1:5173/
```

## 📦 Production Build

```bash
# Compile and validate with TypeScript
npm run build
```
